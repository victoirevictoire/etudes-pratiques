# Etudes Pratiques

## Outil de lecture de schémas électroniques - OCR

## Description
Projet d'études pratiques débuté en 2025-2026. L'objectif du projet est de permettre de faire le lien entre une table de composants, un schéma électronique et une carte électronique. On souhaite que l'utilisateur n'ait qu'à uploader le manuel d'utilisation avant de pouvoir utiliser l'outil.

## Installation
Pour faire tourner l'application, lancer le notebook jupyter NotebookEP (dossier notebook)

## Documents .tex
Editer les documents lateX dans VScode avec une extension dédiée. Installer tectonic pour pouvoir compiler.
Ligne de commande pour générer le pdf du document depuis le code lateX :
/etudes-pratiques/documents_tex$ tectonic <Document>.tex

Le pdf apparaît ensuite dans le répertoire courant
